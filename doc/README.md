# Wirely documentation

Wirely programs are graphs of typed nodes written in `.wrl` files. Start with
the [language guide](language.md) to learn how to declare nodes and connect
them. Then use the [library reference](libraries.md) to find the nodes supplied
with Wirely. The [value type reference](value-types.md) describes the types
used by parameters, connectors, and state.

For `.wrl` formatting and naming, follow the
[Wirely style guide](wirely-style.md).

To implement nodes and procedures in Python, use the
[native Python implementation guide](native-python.md). For Python
contributions, follow the [Python style guide](python-style.md).
